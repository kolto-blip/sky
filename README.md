# Аспан ұшқышы

Жеңіл ұшақтың браузерлік 3D-симуляторы және «Ұшақ қалай ұшады» STEAM-жобасы — бір файлда.

**Ойнау:** `index.html` файлын браузерде ашыңыз немесе GitHub Pages қосыңыз (Settings → Pages → `main` тармағы, `/root` бумасы).

## Ішінде не бар

- **Еркін ұшу** — төбелер, таулар мен көлдер үстінде 450 м биіктіктен бастау.
- **Ұшу және қону** — қонуды 100 балдық шкаламен бағалайтын тапсырма.
- **«Ұшақ қалай ұшады» STEAM-жобасы** — зерттеу жобасы (3 курс): кіріспе, STEAM тәсілі, авиация тарихы, ұшу физикасы, ұшақтың құрылысы, ұшу кезеңдері, тәжірибелер, қорытынды, презентация жоспары, дереккөздер.
- **Ұшудағы зертхана** — ұшақтағы төрт күштің векторлары және формулалардың тірі мәндері.

## Басқару

| Пернелер | Әрекет |
| --- | --- |
| W / S | тұмсық жоғары / төмен |
| A / D | крен солға / оңға |
| Q / E | бұрылу, рульдеу |
| Shift / Ctrl (немесе + / −) | газ |
| F | закрылкалар 0 / 1 / 2 |
| Бос орын | тежегіш |
| C | камера: сырттан / кабина |
| V / L | күш векторлары / зертхана |
| R / Esc | қайта / мәзір |
| M | мотор дыбысы |

Ctrl мен W-ны бірге баспаңыз: браузер бетті жабады.

## Физикалық модель

- Көтеру күші `Y = Cy · ρv²/2 · S`, `Cy` шабуылдың сындық бұрышына (≈15°) дейін сызықты өседі, одан кейін ағын үзіледі.
- Кедергі `X = Cx · ρv²/2 · S`, мұнда `Cx = Cx0 + K·Cy²`, қосымша закрылкалар.
- Бұранданың тарту күші, ауырлық күші, жерге жақын экрандық әсер, дөңгелектердің үйкелісі және тежегіш.
- Параметрлер: массасы 1100 кг, қанат ауданы 16,2 м², тарту күші 4,2 кН дейін. Есептік құлау жылдамдығы ≈96 км/сағ.

## Технологиялар

HTML, CSS, JavaScript, [Three.js r128](https://threejs.org/) (cdnjs арқылы қосылады). Ұшақ кодпен модельденген: фюзеляж — айналу денесі, қанаттар — NACA 2412 профилінің лофты.
