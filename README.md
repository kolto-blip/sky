# Небесный пилот

Браузерный 3D-симулятор лёгкого самолёта и STEAM-жоба «Как летает самолёт» в одном файле.

**Играть:** откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → ветка `main`, папка `/root`).

## Что внутри

- **Свободный полёт** — старт на 450 м над холмами, горами и озёрами.
- **Взлёт и посадка** — задание с оценкой посадки по 100-балльной шкале.
- **STEAM-жоба «Как летает самолёт»** — исследовательский проект (3 курс): введение, STEAM-подход, история авиации, физика полёта, устройство самолёта, этапы полёта, опыты, заключение, план презентации, источники.
- **Лаборатория в полёте** — векторы четырёх сил на самолёте и живые значения формул.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / S | нос вверх / вниз |
| A / D | крен влево / вправо |
| Q / E | рысканье, руление |
| Shift / Ctrl (или + / −) | газ |
| F | закрылки 0 / 1 / 2 |
| Пробел | тормоза |
| C | камера: снаружи / кабина |
| V / L | векторы сил / лаборатория |
| R / Esc | заново / меню |
| M | звук мотора |

Не нажимайте Ctrl вместе с W: браузер закроет вкладку.

## Физическая модель

- Подъёмная сила `Y = Cy · ρv²/2 · S`, линейный рост `Cy` до критического угла атаки ≈15°, затем срыв потока.
- Сопротивление `X = Cx · ρv²/2 · S`, где `Cx = Cx0 + K·Cy²`, плюс закрылки.
- Тяга винта, сила тяжести, экранный эффект у земли, трение колёс и тормоза.
- Параметры: масса 1100 кг, площадь крыла 16,2 м², тяга до 4,2 кН. Расчётная скорость сваливания ≈96 км/ч.

## Технологии

HTML, CSS, JavaScript, [Three.js r128](https://threejs.org/) (подключается с cdnjs). Самолёт смоделирован в коде: фюзеляж — тело вращения, крылья — лофт профиля NACA 2412.
